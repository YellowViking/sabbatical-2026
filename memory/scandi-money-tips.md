## Everywhere in the Nordics

| Habit | Why |
|---|---|
| **Tap water + bottle** | Free and excellent; never buy $3–4 bottles |
| **Hostel / guesthouse kitchen** | Dinner $4–8 vs $25–40 in a restaurant |
| **Discount supermarkets** | See country lists below |
| **Lunch specials** (frokost / dagens) | 30–50% under dinner menus |
| **Book trains early** | DSB Orange / SJ / Vy Lowfare: 40–60% off walk-up |
| **Skip multi-attraction city cards** | 2–3 night stays rarely break even unless you stack 3+ paid museums in 24h |
| **Cashless** | Cards / phone wallets; cash is often refused |
| **Tipping** | Included; round up only if exceptional |
| **eSIM before landing** | ~$5–15; pick a Europe plan that includes **Norway** (not EU+UK only); skip airport kiosks |
| **Free nature first** | Parks, beaches, fortress grounds, hikes |
| **Alcohol is the budget killer** | SE/NO/FI monopolies; bar beer often $8–15. Buy in shops (DK supermarkets, SE Systembolaget, FI groceries up to 8%) and limit bar rounds |

**US travellers:** VAT refunds rarely justify the hassle on small hostel/food spend.

## Denmark

| Tip | Detail |
|---|---|
| **Groceries** | **Netto, Lidl, Rema 1000, Aldi**: ~$10–15/day if cooking · avoid Meny/Irma for staples |
| **Alcohol** | **No monopoly**: beer and wine in normal supermarkets (cheapest in Scandinavia) |
| **Trains** | **DSB Orange** 1–2 months ahead on long legs |
| **Transit** | Skip the Copenhagen Card on a short stay unless you have a heavy museum day; DOT singles/24h only when needed |
| **Free** | Beaches, cliffs, most nature, fortress grounds (e.g. Kastellet) |
| **Trap** | **Nyhavn** café prices: supermarket beer on the quay instead |
| **Lunch** | *Frokosttilbud* ~11:30–14:00 |
| **Museums** | Some have free days (often midweek) |

## Sweden

| Tip | Detail |
|---|---|
| **Groceries** | **Willys, Lidl** cheapest · **ICA / Coop** ~20% more |
| **Alcohol** | **Systembolaget** only for >3.5% ABV · **closes ~15:00 Saturday, shut Sunday**: buy Friday. Bar pint **72–110 kr** vs shop **9.90–29 kr** (Sep 2026) · [Stockholm beer section](stockholm-local-food.md#beer--breweries) |
| **Allemansrätten** | Right of public access: tent for one night, away from houses, leave no trace |
| **Trains** | **SJ** advance fares save a lot |
| **Lunch** | **Dagens lunch** often $11–14 incl. salad, bread and coffee |
| **City cards** | Skip unless 3+ paid sights on the same day |
| **Free** | Parks, many beaches, archipelago nature (the ferry may still need a transit ticket) |
| **Trap** | Tourist streets in Gamla Stan / the waterfront: walk 5 min inland |

## Norway (the most expensive)

| Tip | Detail |
|---|---|
| **Groceries** | **Kiwi, Rema 1000** · First Price brand · **Coop Mega / Meny** = premium |
| **Alcohol** | **Vinmonopolet** for stronger drinks · restaurant beer often **$11–15**: cook and limit bars |
| **Allemannsretten** | Camp on uncultivated land **≥150 m** from houses; respect trailhead rules (no camping in the Preikestolen car parks) |
| **Trains / boats** | **Vy** and **Flåmsbana** sell out: book early; independent tickets beat tour bundles |
| **Hikes** | Trails are free: pay only for a shuttle or cable car if you choose |
| **Lunch** | Dagens where offered, otherwise the supermarket |
| **City cards** | Usually skip |
| **Trap** | Harbour "seafood dinners" at $40+ · cruise-port markups (Torget in Bergen, Skagenkaien in Stavanger, Aker Brygge in Oslo) |
| **Half-board** | Some hotels (e.g. Skagen Brygge) include dinner: compare against dorm + restaurants |

## Finland

| Tip | Detail |
|---|---|
| **Groceries** | Lidl / S-Market / K-Market |
| **Alcohol** | Groceries sell fermented drinks up to **8% ABV** (since June 2024); Alko only for spirits and stronger beer. Pub pint ~€7, craft €8–10 (2026) |
| **Transit** | HSL day ticket on a Suomenlinna day |

## Estonia (cheaper than the Nordics)

| Tip | Detail |
|---|---|
| **Lunch** | **Päevapakkumine** weekday specials ~€5–8 |
| **Groceries** | **Rimi, Selver**: rye bread, picnic for Lahemaa |
| **Market** | **Balti jaam** stalls beat Old Town square restaurants |
| **Trap** | **Raekoja plats** tourist menus |
| **Transit** | Day ticket for Kadriorg + hops, else singles · Bolt late |
| **Beer** | Taproom €4–7 / Old Town €5–9 / Rimi 0.5L €1.71 · Põhjala tour €20 · **public drinking banned** (2026) |

## Latvia + Lithuania (cheaper again)

| Tip | Detail |
|---|---|
| **Riga** | Kitchen + Centrāltirgus (Central Market) |
| **Vivi day trips** | Sigulda / Ķemeri / Jūrmala for a few € |
| **Vilnius** | *Dienos pietūs* lunch sets · Halės market |
| **Trakai** | Kibinai picnic beats the castle terrace |
| **Getting between** | The Tallinn–Riga–Vilnius through train or Lux coaches beat flights |
| **Bolt** | Backup, not default |
| **Beer** | **Cheapest on a Nordic–Baltic route.** Riga 0.3L €3.50–5.50 · Vilnius pint €4–7 · shop 0.5L €1.60–1.80 · brewery-shop cans €1.75–3.50 (2026). Skip €38–60 tours; **Valmiermuiža €16–19** is the one worth it. **Public drinking is fined in Latvia** |
