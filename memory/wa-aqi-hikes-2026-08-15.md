## Recommendation

1. For the selected **Lower Lena + dinner** day from Redmond, use **THEKOI** for the smallest elapsed detour or **Kyoto** for the quickest post-hike arrival and easiest parking.
2. If a **WTA cross-check is mandatory**, use **Grand Forest Figure Eight**: 4.4 miles and +423 feet. It is gentler than Gazzam but meets the stated floor.

## Research method

AllTrails candidates were queried in one browser-side JavaScript batch using its live same-origin suggestion endpoint:

```js
const groups = await Promise.all(queries.map(async query => {
  const response = await fetch(
    "/api/alltrails/explore/v1/suggestions?",
    {
      method: "POST",
      credentials: "include",
      headers: {
        "content-type": "application/json",
        "x-at-caller": "Mugen",
        "x-at-key": currentKey,
        "x-language-locale": "en-US",
        "x-locale-units": "imperial"
      },
      body: JSON.stringify({
        query,
        limit: 12,
        recordTypesToReturn: ["trail"]
      })
    }
  );

  return (await response.json()).searchResults ?? [];
}));
```

Harvest `x-at-key` from one live `POST /api/alltrails/explore/v1/suggestions` network request instead of hardcoding it. The key is part of the web client and may rotate.
