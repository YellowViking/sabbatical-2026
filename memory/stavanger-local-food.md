#### How the Preikestolen shuttle works

1. Buy the **round trip for the exact outbound date/time** at [pulpitrock.no](https://pulpitrock.no/en/); select **Stavanger byterminal (stop 2)**. The outbound ticket is valid only for the printed departure.
2. From Lysefjordgata 12, walk **850 m / about 12 minutes**, mostly flat, via Saudagata/Stiftelsesgata to **Stavanger bussterminal on Jernbaneveien**, beside Stavanger railway station and the south side of Breiavatnet. [Walking map](https://www.google.com/maps/dir/Lysefjordgata+12,+Stavanger/Stavanger+bussterminal,+Jernbaneveien,+Stavanger).
3. Inside the terminal area, follow the numbered **spor/stop** signs to **2**. This is a boarding bay, not bus route 2. Arrive **20 minutes early** and look for the Pulpit Rock Tours/Boreal coach.
4. Show the ticket from the purchase email when boarding. The ride to Preikestolen basecamp is about **50 minutes**; the operator estimates **3–5 hours** for the hike.
5. The return portion works on any scheduled return departure within **four days**, but return buses are **first come, first served**. Queue early for the first desired bus; the round trip does not reserve a specific return seat.

**Friday target:** leave the guesthouse 07:15 → stop 2 by 07:30–07:40 → 08:00 coach if available. The live **Fri Sep 4 return departures from Preikestolen basecamp** are **10:00, 12:35, 13:15, 14:00, 15:30, 16:15, 17:45, 18:15, 19:15 and 20:30 (last bus)**. These are basecamp departure times, not Stavanger arrival times. After an 08:50 arrival, target **13:15** for a ~4h25 trail window; use **14:00** if the hike takes longer. Queue early because seats are first come, first served. Keep the ticket accessible for the entire ride. Customer service: **+47 51 59 90 60**, Mon–Fri 08:00–16:00.
