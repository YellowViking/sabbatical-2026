## All three countries (do everywhere)

| Habit | Why |
|---|---|
| **Tap water + bottle** | Free, excellent — never buy $3–4 bottles |
| **Hostel / guesthouse kitchen** | Dinner $4–8 vs $25–40 restaurant |
| **Discount supermarkets** | See country lists below |
| **Lunch specials** (frokost / dagens) | 30–50% under dinner menus |
| **Book trains early** | DSB Orange / SJ / Vy Lowfare — 40–60% off walk-up |
| **Skip multi-attraction city cards** | 2–3n stays rarely break even (unless you stack 3+ paid museums in 24h) |
| **Cashless** | Cards / Apple Pay; cash often refused |
| **Tip** | Included; round up small only if exceptional (0–10%) |
| **eSIM before landing** | Airalo/Nomad/etc. ~$5–15 — skip airport kiosks |
| **Free nature first** | Parks, beaches, fortress grounds, hikes — core of this trip |
| **Alcohol is the budget killer** | SE/NO monopolies; bar beer often $8–15 — supermarket (DK) or limit |

**US traveler:** VAT refund rarely worth the hassle on small hostel/food spend; don’t plan around it.

## Denmark 🇩🇰

| Tip | Detail |
|---|---|
| **Groceries** | **Netto, Lidl, Rema 1000, Aldi** — aim $10–15/day food if cooking · avoid Meny/Irma for staples |
| **Alcohol** | **No monopoly** — beer/wine in normal supermarkets (cheapest Scandi) |
| **Trains** | **DSB Orange** 1–2 months early on long legs |
| **Transit cards** | Skip “Copenhagen Card” on 3n unless heavy museum day; **DOT** singles/24h only when needed |
| **Free** | Beaches, cliffs, most nature · fortress grounds (e.g. Kastellet) |
| **Trap** | **Nyhavn** café prices — supermarket beer on the quay instead |
| **Lunch** | *Frokosttilbud* ~11:30–14:00 |
| **Museums** | Some free days (often midweek) — check before paying full |

## Sweden 🇸🇪

| Tip | Detail |
|---|---|
| **Groceries** | **Willys, Lidl** cheapest · **ICA / Coop** ~20% more |
| **Alcohol** | **Systembolaget** only for >~3.5% ABV · closed evenings/Sundays · plan ahead · bar beer $8–12 |
| **Allemansrätten** | Right of public access — tent **1 night**, far from houses, leave no trace (not a city hostel substitute) |
| **Trains** | **SJ** advance = large savings |
| **Lunch** | **Dagens lunch** often $11–14 incl. salad/bread/coffee |
| **City cards** | Skip STO/GOT cards unless 3+ paid sights same day |
| **Free** | Parks, many beaches, archipelago nature (ferry may still need transit ticket) |
| **Trap** | Tourist streets in Gamla Stan / waterfront — walk 5 min inland |

## Norway 🇳🇴 *(most expensive on this spine)*

| Tip | Detail |
|---|---|
| **Groceries** | **Kiwi, Rema 1000** · First Price brand · **Coop Mega / Meny** = premium |
| **Alcohol** | **Vinmonopolet** for stronger drinks · restaurant beer often **$11–15** — cook + limit bars |
| **Allemannsretten** | Camp on uncultivated land · **≥150 m** from houses · respect local rules at trailheads (no lot camping at Preikestolen P1/P2) |
| **Trains / boats** | **Vy** + **Flåmsbana** sell out — book early; independent tickets beat tour bundles |
| **Hikes** | Trails free — pay only shuttle/cable if you choose |
| **Lunch** | Dagens where offered · otherwise supermarket |
| **City cards** | Usually skip on 2–3n · stack museums only if 24h pass clearly wins |
| **Trap** | Harbour “seafood dinner” $40+ · cruise-port markups (Torget Bergen, Skagenkaien SVG, Brygge Oslo) |
| **Half-board hack** | Some hotels (e.g. Skagen Brygge style) include dinner — math vs dorm+restaurants |
