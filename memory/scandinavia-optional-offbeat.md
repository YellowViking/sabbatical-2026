# Scandinavia — flexible options & off-beat
*Defaults + how to spend extra/fewer nights · nature-first · late Aug–early Sep 2026 · Jul 2026*

**Mindset:** night counts are a **baseline**, not a contract. Keep route order; move days via the **swing pool** in [itinerary.md](../itinerary.md) §1. Hard limit = **90 Schengen nights** for the whole fall.

**Baseline locked as “good defaults” (not forever):** CPH parks/food recovery · GOT city nature · Preikestolen as Norway hike hero · HEL ferry-in. Everything below is **optional** or **length-dependent**.

---

## If you have extra nights — where they pay off

| Steal → | Put on | Unlocks |
|---|---|---|
| Gotland / Riga crumbs | **CPH +1–2** | Louisiana, Malmö/Lund, Dyrehaven, slower food |
| Gotland skip or −1 | **GOT +1** | Full **Vrångö** day |
| Gotland / Riga | **SVG +1** | Storm buffer / second Lysefjord day |
| — | **Bergen/fjords +1** | Real Aurland overnight without rushing |
| Gotland / Italy | **Bergen/fjords +2–3** | **Early arrival** — solo city days + Rosendal boat day before a companion joins (flex to **9n**) |
| Scandi trim | **Riga** | Cheapest sponge + day trips |
| anywhere careful | **Italy +1–2** | Only if still ≤90 and want slower south |

## Ranked flexible moves (enjoyment first)

1. **CPH +1** after long-haul if wiped  
2. **Bergen block = split base** (even at 5–6n total)  
3. **Gotland 0 or 2** unless you want island days  
4. **GOT +1** only for archipelago  
5. **SVG keep ≥3** if forecast looks wet  
6. **Riga soaks leftovers** before burning Italy buffer  

### Still pace-killers (even with flexibility)
| Idea | Why |
|---|---|
| **Trolltunga** on this spine | 8–12h day; duplicates Preikestolen payoff |
| **Kjerag instead of Preikestolen** | Harder logistics; keep Pulpit as primary |
| **Sigtuna+Uppsala + deep archipelago + full Gotland** | FOMO stack |
| **Adding a new country hop** | Order/spine cost > benefit |
